2. Search concepts

Review and edit the rule-based draft. Synonyms within each concept use OR; selected concepts use AND. Comparison, outcomes and study design are optional to avoid unnecessarily narrowing retrieval.

Clicking Generate strategies sends these criteria to your configured server. The local model extracts concepts, then expands text words; database syntax is compiled by this page. Localhost refers to the computer running your browser. Allow this site's origin in the model server's CORS settings and allow local network access if your browser requests it. Ollama setup · LM Studio setup. The token is never saved or exported.

Add verified MeSH / Emtree headings where available. Machine generation does not invent controlled vocabulary. Exclusion rules remain screening rules; they are not automatically added with NOT.

3. Databases & limits

Some databases support year limits rather than exact dates. The strategy notes show which limits are included. Other is recorded as a note.

Open database

    PubMed and Europe PMC retrieve real records directly. Other databases require institutional access; open the database and import its exported results below.

    * PubMed ESearch exposes at most 10,000 IDs per query. Larger searches are marked Partial and require a documented split or a database / EDirect export. Europe PMC retrieves successive pages. Stopping saves the records already retrieved.

    Method & research references

    Build a small set of core concepts from the inclusion criteria. Expand synonyms and spelling variants, combine terms with OR and concepts with AND, then translate field tags and limits for each database. Review the query with an information specialist and test it against known eligible studies before the final search.

    The local model uses two structured steps: concept extraction with source quotations, then text-word expansion. This implementation has not been validated as a complete systematic-review search method. Dates and exact executed queries are recorded with each retrieval.

    • Cochrane Handbook, Chapter 4 (updated March 2025) — search concepts, synonyms, controlled vocabulary and peer review.
    • TrialMind: Accelerating clinical evidence synthesis with large language models (npj Digital Medicine, 2025) — staged, human-reviewed evidence synthesis.
    • Chained Prompting for Better Systematic Review Search Strategies (2025 preprint) — concept extraction and expansion before Boolean assembly.
    • Reassessing LLM Boolean Query Generation for Systematic Reviews (SIGIR 2025) — query-generation evaluation and sensitivity to model and prompt choices.
    • Webis-SR4ALL-26: A Large-Scale, Cross-Disciplinary Corpus of Systematic Reviews (April 2026 preprint) — linked search strategies and eligibility criteria for benchmarking.
    • litsearchr — text mining and term co-occurrence for search development.
