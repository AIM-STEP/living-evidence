    Method & research references

    Build a small set of core concepts from the inclusion criteria. Expand synonyms and spelling variants, combine terms with OR and concepts with AND, then translate field tags and limits for each database. Review the query with an information specialist and test it against known eligible studies before the final search.

    Machine generate displays model-generated word lists for each eligibility criterion, then uses these words with the database choices and limits to draft database-specific queries. Manual generate combines your word lists using database templates. Supported date and language limits are applied by this page. This implementation has not been validated as a complete systematic-review search method. Dates and exact executed queries are recorded with each retrieval.
