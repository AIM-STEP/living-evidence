# Eligibility Description style

Updated 2026-10-07. Applies to newly generated descriptions; existing author-edited text is not silently rewritten.

The BMJ author guidance requests PRISMA reporting for systematic reviews. PRISMA 2020 item 5 specifies transparent eligibility and synthesis grouping. These sources do not prescribe a single mandatory paragraph template or word count. The implementation uses a concise narrative Methods style as a product editorial choice, not a claim of BMJ endorsement or complete PRISMA compliance.

Primary sources:
- https://www.bmj.com/about-bmj/resources-authors/article-types
- https://www.bmj.com/content/372/bmj.n160 (PRISMA 2020 explanation and elaboration, item 5)
- https://www.bmj.com/content/372/bmj.n71 (PRISMA 2020 statement)

Generation rules:
- Coherent English prose, British spelling; no numbered domain list, headings or metadata in Description.
- Describe eligible studies, not clinical recruitment. Neutral eligibility wording avoids claiming screening has already occurred.
- Cover supplied designs/population, intervention/exposure/concept, comparators, setting, definitions, thresholds and explicit follow-up/outcome requirements. Preserve alternatives and exceptions.
- Outcome interest does not imply mandatory reporting. Dates, language, publication restrictions, absence of restrictions, grouping and rationales are stated only when supplied.
- Explicit exclusions follow inclusion criteria. Do not invent complementary exclusions or add search, reviewer, registration, appraisal or analysis procedures.
- Unresolved conditions stay outside the paragraph and are recorded as uncertainties.
- Existing source/evidence and number validation still applies. When rule validation removes unsupported propositions, a conservative draft is rebuilt from accepted rules and supplied limits; this fallback is not claimed to equal model-edited prose.
- Displayed confirmed-rule handling remains unchanged: hidden clarification rules stay in the complete export; the visible fallback reflects visible criteria. User edits remain available.

Verification: prompt/fallback regression and synthetic local-model generation, plus existing criteria editing/export/confirmation regressions. No claim of journal acceptance or exhaustive semantic validation.
